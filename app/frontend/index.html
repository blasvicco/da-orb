Orb: One conversation. Every SAP Business One process.

Orb is a conversational execution platform by D'Arch Systems.

Orb gives your team a single natural-language interface to run SAP Business One — checking stock, creating purchase requisitions, approving requests, generating invoices — without menus, transaction codes, or waiting on a specialist. Every action is reviewed and confirmed before it runs.

Every process. One conversation.

Today, Orb turns complex SAP Business One workflows into a single guided conversation.

  • Natural Language Operations. Ask for inventory, draft a purchase requisition, or check a vendor status in plain language. No menus, no transaction codes, no specialist required.
  • MCP Server Driven. Orb connects to SAP Business One today through the Model Context Protocol (MCP) — the same architecture that lets future systems be onboarded through configuration, not code, as the roadmap grows.
  • Real-Time Insights. Get live data and status updates straight from your connected systems in seconds, without logging into a separate platform.
  • Governed & Auditable. Every action is reviewed and confirmed before it's submitted, and every conversation is logged — so nothing runs without approval, and nothing is untraceable.

Built for how work really happens

  • Batch Processing. Type your requests in the chat or attach the file. Orb turns every record into its own transaction, runs them all and reports back, for example "2 created, 1 failed".
  • File Content Extraction. Attach a spreadsheet, PDF or export and Orb reads it for you, answering questions about the content or using it to fill in forms. Supports CSV, Excel, ODS, PDF, HTML, JSON, RTF and plain text.
  • Intention Graph. Halfway through a purchase request when someone needs a vendor list? Just ask. Orb parks what you were doing, answers the new request, and picks the first one back up automatically.
  • Projects. Group related chats into projects, such as the Q4 restock or month-end close.
  • File Bucket. Upload documents to your chat's File Bucket and reuse them whenever you need. Documents Orb generates for you, like PDFs, land there too.
  • Multilanguage. Switch the whole interface between English and Spanish at any moment. Orb answers in the language you've chosen.
  • Usage Dashboard. A built-in usage dashboard for organization admins: who's active, which processes run most and where AI usage goes, measured against your plan's seat and token limits.

Enterprise-Grade Security

  • Private by Design. Orb runs inside an isolated private network in the cloud. The only thing ever exposed to the internet is the chat interface itself.
  • Encrypted Everywhere. Every conversation, session, and configuration value is encrypted at rest and in transit. Credentials are kept in a secure vault, never in code or config files.
  • Independently Audited. Orb runs on AWS infrastructure certified against SOC 1 Type II, SOC 2 Type II, and ISO 27001/27017/27018.
  • Zero-Exposure Integrations. Connecting Orb to your SAP Business One environment never requires opening your network to the internet. VPN, Direct Connect, PrivateLink, or VPC Peering keep every connection private and revocable at any time.
